# 모션랩 · 재활 움직임 모니터

React / TypeScript 기반 무릎·어깨 ROM 모니터입니다. MediaPipe Tasks Vision Pose Landmarker의 3차원 world landmarks로 관절 각도를 계산하고, 선택적으로 Hand Landmarker로 양손의 21개 관절을 추적합니다.

## 실행

Node.js 22 이상과 npm을 사용합니다.

```sh
npm ci
npm run dev
```

http://localhost:3000 에서 실행합니다. 카메라는 HTTPS 또는 localhost와 브라우저 권한이 필요합니다. Pose와 Hands 모델을 처음 사용할 때 jsDelivr 및 Google Storage 연결이 필요합니다. 시뮬레이션은 모델 다운로드나 카메라 없이 동작합니다.

```sh
npm run lint
npm test
npx playwright install chromium
npm run test:e2e
# 선택: 실제 모델 동시 실행 검사 (네트워크와 약 30MB 다운로드 필요)
MEDIAPIPE_SMOKE=1 npm run test:e2e -- models.spec.ts
npm run build
NODE_ENV=production npm start
```

GitHub Pages는 기존 배포 workflow에서 `GITHUB_PAGES=true`로 빌드합니다. CSV와 PDF 저장은 정적 배포에서도 지원합니다. AI 요약은 Node API 서버와 `GEMINI_API_KEY`가 있을 때만 동작합니다. 필요하면 `GEMINI_MODEL`로 모델을 지정합니다(기본값 `gemini-2.5-flash`).

## 사용 흐름

1. 웹캠, 영상 업로드 또는 시뮬레이션을 선택합니다.
2. 무릎 또는 어깨 분석을 선택합니다. 어깨는 동작·관찰측·목표·허용각을 설정할 수 있습니다.
3. 골반과 분석 관절이 모두 보이도록 촬영합니다. 어깨 외전은 정면, 어깨 굴곡과 무릎 굴곡은 측면에서 관찰하기 좋습니다. 두 관절 모두 충분한 신뢰도가 필요합니다.
4. 손가락 인식을 켜면 양손 관절을 파란 선으로 표시합니다. 엄지 IP, 나머지 손가락 PIP의 굴곡 추정값을 제공합니다. 손가락 수치는 실시간 표시용이며 ROM 세션 통계·CSV에는 포함하지 않습니다.
5. 리포트 탭에서 관절별 통계와 CSV·인쇄/PDF를 이용합니다. 탭을 바꿔도 영상과 카메라는 유지되며, 일시정지 버튼으로 기록을 멈춥니다.

## 계산과 기록

- 무릎: `180° − angle(hip, knee, ankle)`. 편 상태가 약 0°입니다.
- 어깨: 몸통(shoulder → hip)과 상완(shoulder → elbow)의 3D 사이각입니다. 외전/굴곡 선택은 운동 안내를 의미하며, 해부학적 운동면을 자동으로 분류하거나 분리한 각도는 아닙니다.
- 영상의 가로·세로 비율이 섞인 정규화 좌표로 각도를 계산하지 않습니다. world 좌표가 없거나 필수 관절의 신뢰도가 낮거나 좌표가 유효하지 않으면 수치를 `—`로 표시하고 기록·반복 집계를 중단합니다.
- 표시·반복·최대 ROM에 같은 평활값을 사용합니다. 시간 간격에 따른 EMA(시정수 80ms)는 노이즈를 줄이지만 빠른 움직임의 최고점에 지연과 감소가 생길 수 있습니다.
- 반복은 초기 휴식/선 자세를 확인한 뒤 목표 구간과 복귀를 거쳤을 때 집계합니다. 무릎은 평균 굴곡 60°를 기준으로 하며, 어깨는 설정 목표에 최대 2° 허용오차를 둡니다. 양측 어깨 카운트는 두 팔 모두 목표에 도달해야 합니다.
- 몸통 보상은 world 좌표의 어깨·골반 중심선을 수직축과 비교합니다. 어깨 분석에서만 집계하며 연속된 보상 구간을 1회로 셉니다.
- 시간은 유효한 프레임의 분석 시간이며, 일시정지·추적 실패 시간은 제외합니다. 평균 좌우 차이는 모든 유효 프레임의 산술평균입니다. 실제 프레임 수와 기록 표본 수는 다릅니다.
- 시계열은 약 0.4초 간격, 최근 최대 1,500개 표본을 유지합니다. CSV는 이 표본을 내보내고 요약 통계는 전체 유효 세션을 집계합니다.
- 입력 소스·분석 관절·어깨 동작·관찰측·목표 또는 반복 설정을 변경하면 세션을 초기화하여 서로 다른 조건의 통계를 섞지 않습니다. 새 영상 업로드도 초기화합니다.

## 시뮬레이션

무릎·어깨 선택에 맞는 6초 주기의 합성 동작을 생성합니다. 뼈 길이를 고정하고 삼각함수로 지정한 굴곡각을 생성한 뒤 실제 측정과 같은 계산 경로로 전달합니다. 속도(0.25~2배), 최대 각도(30~150°), 오른쪽 ROM 감소(0~40°), 추적 실패를 조절할 수 있습니다. 일시정지 시 시간·동작·기록이 함께 멈춥니다. 설정 변경 후 비교하려면 “처음부터 재생”을 선택합니다. 보고서와 CSV에 합성 데이터임을 명시합니다.

## 검증 범위

- 기하학 테스트: 0°, 30°, 60°, 90°, 120°, 150°의 무릎·어깨 각도, 비대칭, 유효하지 않은 좌표, 부분/전체 동작 반복, 작은 어깨 목표각, 손가락 각도 및 몸통 기울임.
- 브라우저 테스트: 고정된 Pose 응답을 통한 world 좌표 계산, 모드 전환과 추적 실패, 시뮬레이터 반복/정지, CSV, 리포트, 모바일 가로 넘침. 실제 카메라나 모델의 정확도를 증명하는 테스트는 아닙니다.
- 별도로 공개 MediaPipe `woman_hands.jpg`를 실제 Hand Landmarker 모델로 처리하여 양손 21개 관절과 유효한 손가락 굴곡값이 출력됨을 확인했습니다. 이 이미지는 저장소에 포함하지 않습니다.

카메라 수치는 AI 추정값입니다. 기준 각도계와의 비교, 촬영 조건별 오차·신뢰구간, 임상 검증은 수행하지 않았으며 실제 신체 각도와의 일치를 보장하지 않습니다. 교육·움직임 모니터링 프로토타입입니다.
